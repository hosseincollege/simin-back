# بک‌اند سیمین

API پروژه با NestJS ساخته شده است. سرور توسعه روی پورت `3001` اجرا می‌شود و برای فرانت Angular در `http://localhost:4200`، CORS فعال است.

## اجرای محلی در PowerShell

```powershell
cd E:\hossein\simin\back
npm install
npm run start:dev
```

برای اطمینان از اجرای سرویس، در مرورگر یا پنجره‌ی دیگری این نشانی را باز کنید:

```text
http://localhost:3001/api/health
```

پاسخ سالم:

```json
{"status":"ok","service":"simin-investment-api"}
```

پورت را می‌توان با متغیر محیطی `PORT` تغییر داد. برای اجرای production ابتدا `npm run build` و سپس `npm run start:prod` را اجرا کنید.

## وضعیت فعلی

مسیر بررسی سلامت سرویس و اتصال پایه‌ی فرانت به بک‌اند آماده است. APIهای ثبت‌نام، ورود، ذخیره‌سازی کاربران و فرصت‌های سرمایه‌گذاری هنوز پیاده‌سازی نشده‌اند. داده‌های فرصت‌های نمایش‌داده‌شده در فرانت فعلاً نمونه‌ای هستند.

ماژول مشاهده‌پذیری Nest فعال است، اما تا وقتی کلیدهای Observe تنظیم نشوند، telemetry ارسال نمی‌کند؛ اجرای محلی به این کلیدها نیاز ندارد.
